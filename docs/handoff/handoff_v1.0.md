## 2. 確定済みの仕様(v1.0 で実装済み)
### 全体
- 自分専用、ログインなし。Android スマホ+PC。PWA(インストールしてオフラインで使える)
- データは端末内(localStorage)だけに保存。端末間は「書き出し/読み込み(統合・上書き)」でやりとり
- ライト/ダーク/端末に合わせる、アクセント色3種、文字サイズ4段階、動きを減らす
- デザイン:白黒が基本+アクセント1色、細い区切り線、等幅フォントで番号・型名・日時

### ホーム
- 思考の一覧(番号・タイトル・状態・型・更新日)、絞り込みタブ、並び替え、ピン留め、全文検索
- スワイプで複製/削除(画面の端28pxから始めた操作は無視)、長押しメニュー
- お知らせ行(前回までのエラー件数・書き出しの催促)、今日のドリルの進み具合、＋で新規作成

### テンプレート(6種類)
| キー | 名前 | 構成 |
|---|---|---|
| why | Whyツリー | 問題 → 原因 → 深い原因 |
| how | Howツリー | 目的 → 手段 → 具体策 |
| pyramid | ピラミッド | 結論 → 理由 → 根拠 |
| sky | 空・雨・傘 | テーマ → 空(事実)/雨(解釈)/傘(行動) |
| pros | メリデメ比較 | 比較テーマ → 選択肢(×2〜)→ メリット/デメリット → 内容 |
| blank | 白紙 | テーマ → 項目 |
- 各テンプレートに使い方(ⓘ):目的/手順/記入例/よくある失敗/次にやること
- ビジネス向けサンプル5種(架空の数値と明示)。「この見本をコピーして始める」
- 迷ったら診断(1〜2問で型をすすめる)
- 旧 `tree` テンプレートのデータは自動で `why` に移行

### 作業画面
- アウトライン表示(編集用)とツリー表示(全体確認・拡大縮小)
- 操作バー(下に追加・同階層・右へ・左へ・上へ・下へ・削除)、⋮⋮ でメニュー/ドラッグ並べ替え
- キーボード:Enter / Tab / Shift+Tab / Alt+↑↓ / Ctrl+Z・Y
- 元に戻す/やり直す(アプリを閉じたら履歴は消える)、自動保存と保存状態の表示
- プロパティパネル(スマホは下からのシートで「閉じる/半分/全画面」、PCは右側で折りたたみ):状態、MECEチェックリスト+自動チェック、メモ、AIレビュー履歴、情報
- AIに提出:厳しめ/やさしめ/MECE確認/反論の依頼文+Markdown をコピー・共有、AIの返答を貼り付けて保存
- 集中モード、画像(PNG)書き出し、何も入力せずに離れた思考は自動削除

### ドリル
- 1日5問(日付で固定の出題)、途中から再開、不正解でシェイク、正解3問以上で紙吹雪
- 連続日数、正答率、直近14日のグラフ、「もっと練習する」

### 戻るボタン
| 状態 | 戻る |
|---|---|
| シート・メニュー・確認画面 | 閉じるだけ |
| 作業画面 | 1回目は「もう一度でホームへ」と表示、3秒以内の2回目で戻る |
| ドリル・設定・ゴミ箱 | ホームへ |
| ホーム | 1回目は「もう一度で終了」と表示、2回目で終了 |
- 設定でオフにできる。Android は CloseWatcher、それ以外は History API

### その他
- ゴミ箱(30日で自動削除)、PIN ロック(起動時・1分以上離れたとき)、エラーログ(次回起動時にお知らせ)
- 初回ガイド3枚、用語集、取扱説明書(設定から開ける)、更新の通知、共有ターゲット(他アプリからの共有で新規作成)

## 3. 未実装の決定事項(次に実装する)
### 3-1. 複数タブの自動読み直し(採用済み)
- **背景**:PCで2つのタブを開いていると、後から保存したタブの内容で上書きされてしまう
- **仕様**:
  - `window` の `storage` イベントで、別のタブが `logitore.v1` を変更したことを検知する
  - 検知したら `S` を読み直し、今の画面を描き直す。作業画面で開いている思考が消えていたらホームへ戻る
  - 読み直したことはトーストで知らせる(例:「別のタブの変更を読み込みました」)
  - 入力中の文字を失わないよう、未保存の変更がある場合は先に保存してから読み直す
- **変更対象**:`index.html`(保存まわり・起動処理)、`manual.html`(注意書き)
- **受け入れ条件**:
  - タブAで思考を追加すると、タブBの一覧に数秒以内に表示される
  - タブBで別の思考を編集して閉じても、タブAで追加した思考が消えない
  - 既存の自動テストがすべて成功する

## 6. 既知の制限
- Android の戻るボタンは実機で未確認(自動テストは Esc キーで代用)
- `file://` で直接開いた場合はインストールできない。インストールは公開アドレスから
- データはアドレス(サイト)ごとに別々に保存される。`file://` で使っていたデータは「書き出し→読み込み」で移す必要がある
- 会社の PC など、管理者の設定でインストールの表示が出ない場合がある
- テスト環境:Python 版 Playwright が必要(クラウド環境「PWA-app」では起動時に自動で入る設定。初回の新しいセッションで動作を確認すること)
